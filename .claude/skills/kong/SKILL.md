## 1. Please use the last available Kong OSS version for OSS projects

According to Kong's documentation online, recent gateway versions are not free. In this case please keep `kong` images updated to the latest free version.

Please read the documentation here:

- https://developer.konghq.com/gateway/upgrade/lts-upgrade-34-310
- https://developer.konghq.com/gateway/changelog
